# LLM Tokenizer Fertility & Serving Capacity Audit

A technical audit and experimental benchmark suite evaluating LLM tokenizer fertility across multilingual corpora (English and Hindi) and its downstream impact on LLM serving capacity and cost.

## Repository Structure

- `starter_kit/`: Read-only reference containing the original intern's code (`fertility.py`), benchmark logs (`bench/`), sample corpora (`corpus_sample/`), and initial report (`REPORT_v0.md`).
- `scripts/`: Modular automation scripts for capturing baseline measurements, running experiments, and auditing benchmarks.
- `NOTEBOOK.md`: Chronological log of hypotheses, experiments, and results following the Evidence Rule.
- `AI_USAGE.md`: Documentation of AI assistance and audit standards.
- `requirements.txt`: Python package dependencies.
